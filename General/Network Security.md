# AWS Network Security

## Security Groups

Security Groups are firewall(A term assoicated with creating a wall that confines the spread of fire) that controls how traffic is allowed in and out of our EC2 Instances.

The job of the security group is to regulate the following:

1. Access Ports
2. Authorized IP ranges - IPv4 and IPv6
3. Control Inbound(Ingress) and Outbound network(Egress)
